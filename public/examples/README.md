# Examples

These files are the checked-in samples used by the app and the tests. They
are generated from `src/import/examples/catalog.ts` (the single source of
truth) — do not edit them independently.

- `atlas-q3-brief.json` — the preloaded "Project Atlas" decision brief in the
  strict deterministic JSON format (`version`, `title`, six typed blocks).
- `atlas-launch-notes.md` — the same information as Markdown notes, used to
  demonstrate the lossless local text parser and the curated verified-example
  extraction.
